GitHub CI 在没有构建产物时会跳过 Windows mock DLL 测试及适配库 ELF 检查，不运行 NPU。以 Actions 对应提交的结果为准。本机测试中的 NPU_TRIAL_FAILED 等输出来自预期的故障注入用例，不是本轮真实板端失败。
